# Tasks

- [`current.md`](./current.md) — việc đang làm. Đọc trước khi bắt đầu bất kỳ task nào. Cập nhật khi trạng thái đổi; khi task xong, tóm tắt kết quả vào [`../logs/`](../logs/README.md) rồi dọn file này về trạng thái trống/task tiếp theo.
- [`backlog.md`](./backlog.md) — việc chưa làm, chưa có ai nhận. Không phải nơi lưu lịch sử — việc đã xong chuyển sang [`../history/milestones.md`](../history/milestones.md).

# Logs

Nhật ký phát triển theo ngày, file `YYYY-MM-DD.md`. Trả lời câu hỏi "việc gì đã xảy ra?" — khác với `history/`, trả lời "tại sao hệ thống như vậy?".

- Ghi log sau mỗi phiên làm việc **có ý nghĩa** (không ghi cho thao tác vặt).
- Nhiều task trong cùng ngày → thêm nhiều section trong cùng file ngày đó.
- Đọc log gần nhất khi tiếp tục việc dở dang từ phiên trước.
